Notation

Activez la notation et choisissez les types d'éléments qui peuvent être notés (billets, commentaires, catégories, mots-clés, événements, liens cinecturlink) depuis la configuration de l'extension. Trois styles sont disponibles : classique (le visiteur donne une note), double (le visiteur dit s'il aime ou non) et simple (le visiteur dit seulement s'il aime).

La notation est affichée après le contenu des billets ou des commentaires selon les options des modules, avec le widget « Rate it : notation », ou avec les balises de template (voir le template rateit.html qui peut être copié dans votre thème).

Votes

Les visiteurs sont identifiés par leur adresse IP, par un cookie ou par les deux. Les adresses IP ne sont pas enregistrées, seule une empreinte l'est. Cette page liste les éléments notés, cliquez sur un élément pour voir et supprimer ses votes.

Balises de template

  • <tpl:rateIt type="post" style="classic"> : bloc de notation de l'élément courant (attributs facultatifs)
  • <tpl:rateItIf has_vote="1" user_voted="0" type="post" style="!twin"> : conditions
  • {{tpl:rateItTitle}}, {{tpl:rateItLinker}}, {{tpl:rateItAnchor}}
  • {{tpl:rateItNote}}, {{tpl:rateItFullnote}}, {{tpl:rateItQuotient}}, {{tpl:rateItMax}}, {{tpl:rateItMin}}
  • {{tpl:rateItTotal totaltext="1" none="aucun vote" one="un vote" more="%d votes"}}, {{tpl:rateItMaxCount}}, {{tpl:rateItMinCount}}
